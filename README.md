# TvDesk — تلویزیون و والپیپر زنده‌ی دسکتاپ (ویندوز)

یک اپ هیبریدی: هم تلویزیون دسکتاپ (کتابخانه‌ی بزرگ کانال‌های IPTV اپن‌سورس) و هم والپیپر زنده (پخش ویدیو/استریم پشت آیکون‌های دسکتاپ، شبیه Wallpaper Engine).

## قابلیت‌ها
- پخش ویدیو/استریم روی دسکتاپ پشت آیکون‌ها (ترفند WorkerW)
- کتابخانه‌ی داخلی IPTV (iptv-org) با تفکیک کشور/دسته/زبان + کانال‌های تلوبیون
- ورودی لینک تکی: یوتیوب / آپارات / تلوبیون (از طریق yt-dlp)
- عوض‌کردن آنی کانال (بدون play/pause/seek)
- کنترل صدا (کم/زیاد/میوت)، دکمه‌ی هاید/آنهاید آیکون‌ها
- کانال‌های منتخب، جستجو/فیلتر، لوگوی کانال‌ها
- رفتار هوشمند: میوت هنگام فوکوس اپ دیگر، توقف هنگام فول‌اسکرین
- هات‌کی سراسری، اجرای خودکار با ویندوز، یادآوری آخرین کانال
- تنظیم کیفیت ترجیحی (Auto/High/Medium/Low)

### هات‌کی‌ها
- `Ctrl+Alt+D` — هاید/آنهاید آیکون‌های دسکتاپ
- `Ctrl+Alt+M` — میوت/صدا
- `Ctrl+Alt+T` — باز کردن پنل کنترل

## بیلد با GitHub Actions (بدون نیاز به بیلد محلی)

1. این پوشه را به عنوان یک ریپوی جدید روی GitHub پوش کن:
   ```bash
   git init
   git add .
   git commit -m "initial: TvDesk"
   git branch -M main
   git remote add origin https://github.com/<USER>/TvDesk.git
   git push -u origin main
   ```
2. با هر push، تب **Actions** خودکار بیلد می‌گیرد. فایل خروجی (`TvDesk-win-x64.zip`) در بخش **Artifacts** همان ران قابل دانلود است.
3. برای ساخت یک **Release** آماده‌ی دانلود، یک تگ نسخه بزن:
   ```bash
   git tag v1.0.0
   git push origin v1.0.0
   ```

> `yt-dlp.exe` در زمان بیلد در CI دانلود و کنار اپ بسته‌بندی می‌شود. کتابخانه‌های native خود LibVLC از پکیج `VideoLAN.LibVLC.Windows` خودکار اضافه می‌شوند.

### اگر single-file به مشکل خورد
LibVLC تعداد زیادی پلاگین native دارد؛ اگر حالت single-file باعث خطا شد، در `build.yml` فلگ `-p:PublishSingleFile=true` را بردار تا خروجی به‌صورت پوشه‌ی کامل باشد.

## اجرا
فایل zip را اکسترکت کن و `TvDesk.exe` را اجرا کن. با `--self-contained` به نصب .NET نیازی نیست.

## نکته‌ی حقوقی
TvDesk فقط پلی‌لیست‌های عمومی و رایگان را پخش می‌کند. مسئولیت رعایت قوانین کپی‌رایت و دسترسی مجاز به محتوا بر عهده‌ی کاربر است. بعضی کانال‌ها ممکن است region-lock باشند.
